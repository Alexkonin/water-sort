# Арсенал Towers

[Открыть каталог](index.html).

Пять объектов: Пушка, Замок, Мороз, Молния, Мортира. Для каждого — отдельная папка с index.html, building.json, README.md, art/ и animations/.

## Единая концепция

Лесная крепость: мшистый камень, состаренная бронза, дерево, охристые крыши и тёплые окна. Компактные объёмы, общая ортографическая камера около 45°, свет сверху слева. Разные силуэты оружия сохраняют читаемость без цвета. Это предложение v01, а не утверждённые модели.

Порядок: Пушка → Замок → Мороз → Молния → Мортира. Для каждого: силуэт, материалы, ракурсы, пять разрядов, анимация, проверка на игровом поле, утверждение.

## Источники и статусы

- `_shared/current-renderer.js` — изолированный снимок рисунков и параметров классической игры из `../tower-defense.html`. Никаких сохранений и боевого цикла; поворот — только просмотр.
- `catalog.json` содержит дату снимка, хеш игрового исходника и концептуальные карточки; `_shared/catalog.js` — их браузерная копия для открытия без сервера.
- `../diorama-art/buildings-v01.png` — существующий общий атлас. `../diorama-art/v02/cannon-turns.png` — ракурсы оружия Пушки. Ссылки ведут к оригиналам, файлы не дублируются.
- Для Мортиры пока нет отдельного растрового концепта. Все пять художественных разрядов каждой постройки предстоит разработать.

Рисунки игры на странице не выдаются за будущие модели диорамы. Числа — снимок от 04.10.2026; источник баланса остаётся в игре. Обновление рисунков: `python3 scripts/sync-arsenal.py` из корня проекта. При обновлении в другой день поправить дату снимка и подпись в viewer.js. Тексты карточек при синхронизации не перезаписываются; править согласованно building.json, catalog.json и _shared/catalog.js.

## Версии

Новые концепты сохранять в `art/` с суффиксом v01, v02; прототипы — в `animations/`. Статусы: к обсуждению → эскиз → прототип → утверждён → в игре. Утверждённые варианты не перезаписывать. Для замка отдельно проверять прочность 100%, 50%, 20% и появление гарнизона только с IV разряда.
