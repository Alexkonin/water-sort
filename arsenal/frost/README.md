# Мороз

[Открыть карточку](index.html). Статус: к обсуждению.

Небольшой урон и замедление; сила и длительность замедления растут с разрядом.

## Направление

Вертикальный мятный кристалл в каменной чаше. Матовая опора, светящиеся грани; узнаваемость по острому силуэту.

## Движение

Свет собирается в центре → холодный импульс → медленное затухание.
