# Мортира

[Открыть карточку](index.html). Статус: к обсуждению.

Редкие мощные выстрелы; радиус взрыва растёт с разрядом.

## Направление

Широкий короткий ствол, поднятый вверх, тяжёлая люлька и боковые упоры. Бронза с медным акцентом.

## Движение

Медленное наведение → тяжёлая отдача → снаряд по дуге → взрыв.

## Следующий шаг

Нужен самостоятельный концепт диорамы: отделить силуэт от Пушки даже без цвета.

Версии концептов хранить в art/, прототипы в animations/. Новые варианты: v01, v02. Утверждение фиксировать отдельно; текущее направление пока не утверждено.
