Навесной выстрел

Нажмите «Выстрел»: отдача, полёт по дуге, взрыв. Это визуальная демонстрация по неподвижным мишеням, не симуляция боя. При включённом уменьшении движения показываем только результат попадания.

Прототип для обсуждения. Показатели урона, скорости стрельбы и радиуса взрыва сохранены. Пока не опубликовано.
