# Дождевик: полный игровой цикл

[Интерактивный просмотр](prototype-v01/index.html) · [общий рендерер Дождевика и Спорки](dozhdevik.js).

Статус: подключено к локальной игре; публикация ещё не выполнена. Вид сверху по 3D-концепту: чешуйчатое тело, отверстие на макушке, короткие ножки из мицелия. Это процедурная 2.5D-графика, не 3D-меш.

- Движение: чередование двух ножек, мягкое покачивание и сжатие тела. Фаза зависит от пройденного расстояния; мороз замедляет и походку.
- Атака: сжатие → выброс споровой пыли → контакт с воротами → восстановление. Цикл 0,9 с, контакт на 58%; урон управляется прежним таймером осады. Пыль не создаёт новых врагов.
- Гибель: оболочка сразу раскалывается, кусочки и пыль растворяются за 0,8 с. Эффект расположен в реальной точке гибели, включая осаду.
- Появление: четыре живые Спорки создаются сразу, по прежнему правилу позади родителя на той же дороге, с тем же масштабированием волны. При появлении разворачиваются из маленького зерна за 0,45 с. Это визуальный эффект, без неуязвимости или задержки завершения волны. Прототип показывает их веером для удобства просмотра; в игре они следуют дороге.
- Спорка: маленькое чешуйчатое тело с хвостиком, короткими ножками и прыжками. Модель основана на отдельном концепте.

Баланс сохранён: Дождевик 60 HP, скорость 1, броня 0, награда 16, удар 1 раз в 1,8 с. Спорка 8 HP, скорость 2,4, награда 2. На осаде действуют прежние правила урона и появления.

Проверки: однократная гибель, ровно четыре спорки, сохранение дороги и масштаба, немедленная уязвимость, отсутствие рекурсивного распада, контакт атаки, корректность рисунка на всех фазах.

## Рост Спорок · v102

Спорки любого поколения через 8 секунд становятся Дождевиками, сохраняя долю здоровья. Каждое следующее поколение также может вырасти и дать потомство. [Правила и просмотр](../../sporka/animations/prototype-v01/index.html).
