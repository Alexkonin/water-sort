# Светлячок: графика

[Актуальный 3D-концепт v02](mascot-sheet-v02.png) · [промпт](mascot-sheet-v02.prompt.txt).

Лесной дух света: компактное тело, листовые надкрылья, тёмная голова с янтарными глазами-щелями, усики-побеги и светящееся брюшко. Образ переработан в стилистике игровых духов вместо натуралистичного жука. Растровый концепт создан встроенным ImageGen; [игровая модель с полётом и атакой](../animations/prototype-v02/index.html) подключена локально.
