# Гулень: анимации

[Прототип v110](prototype-v01/index.html?v=110). Общий модуль игры — `gulen.js`.

Вид сверху: мшистая спина, папоротник, корневые лапы, поперечное полое бревно. Шаг зависит от расстояния. Удар 1,1 с, контакт на 60% совпадает с уроном воротам. По дороге удар каждые 3 с синхронизирован с выдачей Гула жизни; кольцо показывает радиус 1,4 клетки.

Локальная версия, без публикации.

Версия v111: новый грушевидный силуэт спины, боковые руки под корпусом, короткие хватательные лапы по краям бревна, объёмная кора и мелкие мшистые участки. Механика Гула жизни прежняя.
