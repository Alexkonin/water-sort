# Хозяин леса: анимации

[Прототип v118](prototype-v01/index.html?v=118). Модуль `forest-lord.js`.

Строгий вид сверху, четыре корневые лапы со сдвигом фазы шага, слои коры и мха, дубовые рога и папоротник. Шаги зависят от расстояния, остановка останавливает походку.

Атака 1,4 с: упор, опускание рогов, таран, возврат. Контакт на 62% совпадает с уроном воротам; земля разлетается в момент попадания. Подключено только к boss skin=0, остальные облики сохраняют прежние правила и анимации. Общий баланс босса сохранён. Локальная версия.
