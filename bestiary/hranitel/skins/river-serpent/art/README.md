# Речной змей — 3D-концепт

[Концепт v05](mascot-sheet-v05.png): сверхъестественная версия одобренной основы v04. Светящиеся глаза без зрачков, течение с огоньками внутри тела, водяные ленты плавников и растворяющийся в струях хвост. Сохранён массивный силуэт древнего хранителя.

Версии v01–v03 — архив отвергнутых направлений. v04 — созданная с нуля основа, которую пользователь одобрил перед добавлением сверхъестественных черт. v05 одобрен пользователем. Игровая модель обновлена по v05.
