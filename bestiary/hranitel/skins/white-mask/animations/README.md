# Белая маска: анимации

[Прототип v119](prototype-v01/index.html?v=119). Общий модуль `white-mask.js`.

Вид сверху: крупная берестяная маска, тёмная листовая мантия, корневой шлейф, ветвистые руки. Парение и колыхание продолжаются на остановке, поток листвы зависит также от расстояния.

Атака 1,25 с: широкий замах, движение корпуса вперёд, сведение ветвей у цели, возврат. Контакт на 60% совпадает с уроном; руки постоянно соединены с плечами. Изменён только boss skin=1, прочие облики сохраняют своё поведение. Баланс прежний. Локальная версия.
