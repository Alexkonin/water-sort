# Кротень: графика

[3D-концепт v01](mascot-sheet-v01.png) · [промпт](mascot-sheet-v01.prompt.txt).

Подземный лесной дух с розовым носом, земляными лапами-лопатами, короткими когтями и мшистой спиной. Общий вид, профиль, спина, вид сверху, закапывание и появление. Создан встроенным ImageGen. Растровый концепт, не 3D-меш; [игровая модель и анимации](../animations/prototype-v01/index.html) подключены локально.
