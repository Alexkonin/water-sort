# Росник: течение, лечение и атака

[Интерактивный просмотр](prototype-v01/index.html) · [Общий рендерер](rosnik.js).

Локальная игровая версия v106, вид сверху по 3D-концепту. Водяное тело с внутренним светящимся духом, листком и пузырьками. Скользит по земле, сжимаясь и вытягиваясь по пройденному расстоянию; без ног и прыжков.

Лечение: капли идут к раненым живым соседям в радиусе 1,2 клетки. Восстанавливается 2% их максимального HP в секунду, максимум до полного здоровья. Себя и осаждающих замок не лечит; при своей осаде прекращает лечение. Несколько Росников не складывают эффект. Выбор целей обновляется каждый шаг мира. Частицы только показывают действие непрерывного лечения, не являются отдельными лечебными снарядами.

Атака: собирается в плотную каплю, вытягивает водяной хлыст до реальных координат ворот, разбрызгивает кончик и возвращает воду в тело. Цикл 1 с, контакт на 60%, синхронизирован с прежним таймером осады.

Параметры сохранены: HP 80, скорость 1,1, награда 42, удар 1 каждые 1,8 с. Модель и эффекты не меняют боевые координаты. Прототип лечения — наглядная демонстрация двух раненых и одного здорового соседа с переключением радиуса.
