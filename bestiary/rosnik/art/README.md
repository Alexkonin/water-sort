# Росник: графика

[3D-концепт v01](mascot-sheet-v01.png) · [промпт](mascot-sheet-v01.prompt.txt).

Прозрачная аквамариновая капля с маленьким светящимся духом внутри, зелёным листком и пузырьками. Лист показывает общий вид, ракурсы, вид сверху и исцеление соседей каплями росы. Растровый концепт создан встроенным ImageGen, это не 3D-меш. [Игровая модель, лечение и атака](../animations/prototype-v01/index.html) подключены локально.
