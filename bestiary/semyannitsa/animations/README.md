# Семянница: анимации

[Прототип v113](prototype-v01/index.html?v=113). Общий модуль `semyannitsa.js`.

Переваливающаяся походка зависит от расстояния. Пуховая крона движется с отставанием от корпуса. Каждые 2,2 с (мороз замедляет) рождается отдельная Пушинка: полёт назад по тому же маршруту 0,65 с, плавное раскрытие от 35% до полного размера. Пушинка уязвима сразу и существует независимо от матери. После отлёта движется обычным способом. Предел 8 за жизнь сохранён, у ворот выпуск прекращается.

Локальная версия, без публикации.
