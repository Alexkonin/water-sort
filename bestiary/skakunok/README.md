## Текущее поведение

- каждые 2,4 с прыгает на 1,5 клетки вперёд; мортира по нему промахивается

Подсказка игры: прыгает на полторы клетки разом — мортира с упреждением по нему мажет.

Базовые числа: здоровье 55, скорость 1.3 клетки/с, броня 0, награда 24, урон замку 1, интервал удара 1.2 с. Фактические числа в бою могут масштабироваться. Доступность с карты 75 не означает появление в её первой волне; точное правило сохранено в creature.json.

## Материалы и статус

Подготовлен [3D-концепт](art/mascot-sheet-v01.png): листовой дух-кузнечик, ракурсы, вид сверху, подготовка к прыжку и прыжок. Игровая модель обновлена по концепту: [прыжки и атака](animations/prototype-v01/index.html?v=112).

Следующая проработка: силуэт и вид сверху, восемь направлений, ожидание, ходьба, атака, получение урона, гибель; проверка в 24/32/48 px.
