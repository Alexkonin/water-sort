# Скакунок: анимации

[Прототип v112](prototype-v01/index.html?v=112). Общий модуль `skakunok.js`.

Вид сверху: два листовых надкрылья с прожилками, сильные складные задние лапы, короткие передние лапки, усики с листочками. По дороге: шаги, подготовка 0,22 с, полёт 0,3 с на 1,5 клетки, посадка 0,18 с. Существующая механика прыжков и уязвимости сохранена.

Атака: сжатие лап, прыжок корпусом к воротам и возврат. Длительность 0,8 с, контакт на 60%, синхронно с игровым уроном. Модуль рисования не перемещает объект в мире и не наносит урон.

Локальная версия, без публикации.
