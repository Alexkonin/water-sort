# Соломенник: анимации

[Открыть прототип](prototype-v01/index.html?v=109). Общий модуль игры и бестиария: `solomennik.js`.

Вид сверху по концепту v02: тонкая светлая солома, тёмная глубина снопа, пояс с узлом, колосья и глаза-угольки. Шаги и переваливание зависят от пройденного расстояния; стебли слегка колышутся во времени.

Атака длится 0,9 с, контакт на 60% совпадает с игровым уроном. Корпус приближается к воротам, короткая связанная с плечом рука делает взмах, затем герой возвращается. Модуль рисования не наносит урон сам.

Баланс прежний: HP 110, скорость 1,2, броня 0, урон 1 раз в 1,5 с. Пушка ×0,5, мортира ×2. Версия локальная, v109.
