# Туманник: скольжение, покров и атака

[Открыть интерактивный просмотр](prototype-v01/index.html). [Canvas-рендерер](tumannik.js).

Статус: локальная игровая версия. Процедурная 2.5D-модель с объёмными полупрозрачными клубами, тремя шлейфами и белой маской без рта. Маска скользит плавно, внутренние потоки движутся и в ожидании. Подпрыгивание удалено.

Атака: сжимает облако, вытягивает туманный жгут к воротам, рассеивает его после контакта. Цикл 0.9 секунды, контакт на 55%. Урон 1 и интервал 1.2 секунды сохранены, нанесение урона остаётся в симуляции. Мороз не замедляет.

## Туманный покров — первый баланс

Радиус 1.4 клетки от центра. Пока Туманник движется, прямые снаряды по соседям получают множитель точности 0.65. Он не защищает себя; несколько источников не усиливают эффект. Покров не блокирует выбор цели, а уменьшает вероятность попадания. Поддерживаемые виды: ядро, стрела, баллиста, мороз. Молния и взрыв по площади не получают штрафа.

Пушинка сохраняет свою маленькую цель: 0.35 × 0.65 = 22.75% для пушки без мороза. Обычный союзник получает 65% точности противника. У осаждающих союзников покров не работает. Проверка выполняется в момент попадания по текущим позициям; мёртвый, скрытый, остановленный или осаждающий источник покров не даёт.

Соседи изображаются полупрозрачными с дымкой. Числа пока стартовые; проходимость кампании с новой аурой требует игровых прогонов.
