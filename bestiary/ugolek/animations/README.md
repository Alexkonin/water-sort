# Уголёк: анимации в игре

[Посмотреть](prototype-v1/index.html) · [Рабочий рендерер](ugolek.js) · [Описание интеграции](prototype-v1/integration.txt).

Один рендерер используется в Towers, бестиарии, листе направлений и просмотрщике.
Реализованы ожидание, ходьба по расстоянию, поворот, подготовка атаки, контакт и восстановление.
Урон остаётся в симуляции; отрисовка не меняет бой. Старый рисунок Уголька удалён.

Атака v02: бросок части огонька. Отделение на 16% цикла, полёт по дуге, попадание на 46% в момент штатного урона. Огонёк в руках остаётся и восстанавливается после броска. В классической игре цель вычисляется от реальной позиции осады до ворот. Частота и урон прежние; искра — визуальная часть атаки, её полёт замедляется вместе с таймером осады.
