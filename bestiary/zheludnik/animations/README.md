# Желудник: анимации

[Прототип v114](prototype-v01/index.html?v=114). Общий модуль игры — `zheludnik.js`.

Вид сверху: скорлупа с древесным рисунком, чешуйчатая шляпка, черешок и дубовый листок. Целый — тяжёлое переваливание, треснувший — частые шаги корней. Шаги зависят от расстояния.

Атака длится 1 с: отклонение назад, таран острым краем, возврат. Контакт на 60% совпадает с игровым уроном. Раскол открывает сердцевину и разбрасывает кусочки в течение 0,5 с. Броня и ускорение прежние. Локальная версия.
